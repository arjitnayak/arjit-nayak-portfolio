# Arjit Nayak — Portfolio

Personal portfolio site: a single self-contained `index.html` (no build step, no
external JS/CSS files — everything, including photos and the résumé PDF, is
inlined).

## Running locally

Just open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

## Deploying with GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `/ (root)`. The site will
be served at `https://<username>.github.io/<repo-name>/`.
